Overview

A browser-based timer for the Timer role at Toastmasters Club 675E meetings. It shows green, yellow and red cards at the Item 675E times for each speech type, on a display window only the audience sees, while the clock stays on your own screen.

Features

The card changes colour automatically at the times from the 675E script:

Table Topics (up to 2 min)1:001:302:00
Ice Breaker (4-6 min)4:005:006:00
Other speech (5-7 min)5:006:007:00
Evaluation (2-3 min)2:002:303:00
  • Private clock: the control window shows the clock and thresholds. The separate display window shows only the colour, with no text or numbers.
  • Speech type selector: four buttons, locked while the clock runs so you can't change type by accident.
  • Manual override: pin the display to green, yellow, red or none if something misbehaves. A MANUAL badge shows, and Back to Auto returns to the clock.
  • Timer log: record each speaker's name, time and whether they were within time, then export it as a PDF.
  • Shortcuts: Space starts or pauses, R resets, 1-4 pick the type, G / Y / X / N set green, yellow, red or none, A returns to auto.

How to use it in a meeting

  1. Open the app in Chrome and click Open display window.
  2. On Zoom or Meet, share only the display window (double-click it for fullscreen). Keep the control window to yourself.
  3. Pick the speech type before the speaker starts.
  4. Press Start (or Space) when they begin. The display changes colour at the green, yellow and red marks.
  5. Press Pause when they finish, optionally type their name, and click Log this time.
  6. Press Reset before the next speaker.

If the colour is wrong, click a colour button to pin it, then Back to Auto to hand control back to the clock. Keep the control window in its own window, not a background tab, so the browser doesn't slow the clock.

Exporting the timer log as PDF

The export prints the log in the layout of page 2 of the 675E Timer Script and Log.

  1. Log each speaker during the meeting with Log this time.
  2. In the Timer log card, set the Meeting date (it defaults to today) and choose Letter or A4.
  3. Click Export PDF. The browser's print dialog opens.
  4. Set the destination to Save as PDF and save.

The PDF has three tables: Table Topics (Name, Time, Within time), Prepared Speeches (Name, Speech Time Requirement, Actual Time, Within time) and Evaluations (Name, Actual Time, Within time). Ice Breaker and Other speech both go under Prepared Speeches. Blank rows are left in each table for handwriting extra entries.

“Within time” is Y when the actual time falls between the green and red marks, and N otherwise.
